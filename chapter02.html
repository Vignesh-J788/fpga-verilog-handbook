Logic Gates & Boolean Algebra

Chapter 1 gave you 1s and 0s. This chapter gives you the tiny decision-making machines — gates — that combine those 1s and 0s into logic, and the algebra that lets you predict and simplify their behavior on paper before you ever touch hardware.

📖 Beginner Level🕐 —🧩 11 sections

What Exactly Is a "Logic Gate"?

A logic gate is the tiniest possible decision-maker in electronics. It looks at one or more inputs — each either HIGH (1) or LOW (0) — and instantly produces one output, also either 1 or 0, based on a fixed rule. That's the entire idea. Every calculator, every processor, every FPGA you will ever program is, underneath everything, just millions of these tiny decision-makers wired together.

Analogy · Two Friends and a Bulb

Imagine two friends, A and B, each holding a switch that's wired to one shared light bulb. Depending on how the switches are wired to the bulb, you get a different rule for when the bulb glows. If the bulb only glows when both friends press their switch — that's an AND gate. If it glows when either one (or both) presses — that's an OR gate. The wiring pattern is the logic. We're about to go through every common wiring pattern, one at a time.

For every gate below, we'll show: the real-life analogy, the standard symbol used on schematics worldwide, the truth table (every possible input combination and its result), and the Boolean expression (the algebra shorthand for the rule).

NAND and NOR — The "Universal" Gates

NAND is simply "Not-AND" — an AND gate with a bubble on the output. NOR is "Not-OR" — an OR gate with a bubble on the output. They just flip the final answer of their sibling gate.

Why are these called "Universal"?

Here's something genuinely beautiful: using only NAND gates (or, separately, only NOR gates), you can build every other gate that exists — AND, OR, NOT, XOR, everything. This is why chip manufacturers often build entire circuits out of a single repeated gate type — it massively simplifies manufacturing. For example, wire both inputs of a NAND gate to the same signal, and you've built a NOT gate for free — because (A·A)' = A'.

Analogy · Two Friends Who Only Agree to Disagree

Imagine A and B are two people voting Yes/No on something. XOR's bulb glows only when they voted differently. XNOR's bulb glows only when they voted the same. That's the entire idea — XOR spots disagreement, XNOR spots agreement.

Boolean Algebra — The Rules of the Game

Boolean algebra is just ordinary algebra, except every variable can only ever be 0 or 1. It gives us a set of proven laws that let us simplify a complicated logic expression into a smaller, cheaper one — smaller expressions mean fewer gates, which means a smaller, faster, cheaper chip.

LawAND formOR form
IdentityA · 1 = AA + 0 = A
NullA · 0 = 0A + 1 = 1
IdempotentA · A = AA + A = A
ComplementA · A' = 0A + A' = 1
CommutativeA·B = B·AA+B = B+A
Associative(A·B)·C = A·(B·C)(A+B)+C = A+(B+C)
DistributiveA·(B+C) = AB+ACA+(B·C) = (A+B)(A+C)
AbsorptionA + A·B = AA·(A+B) = A
A sneak peek: DeMorgan's Theorem
There's one more extremely powerful law — DeMorgan's Theorem, which lets you flip a NAND into an OR-of-inverted-inputs, and a NOR into an AND-of-inverted-inputs: (A·B)' = A' + B' and (A+B)' = A'·B'. It's so important it gets its own full chapter next (Chapter 3), including Karnaugh Maps — a visual shortcut for simplification.

Worked Simplification Example

Let's simplify Y = A·B + A·B' + A'·B using the laws above:

boolean simplification
Y = A·B + A·B' + A'·B
  = A·(B + B') + A'·B     // grouped first two terms, factored out A
  = A·(1) + A'·B          // Complement law: B + B' = 1
  = A + A'·B              // Identity law: A·1 = A
  = A + B                 // Absorption-family identity: A + A'B = A + B

We turned a 3-term, 5-variable-use expression into just A + B — a single OR gate instead of two AND gates, one OR gate, and two inverters. That's the entire point of Boolean algebra: fewer gates, same behavior.

Summary

A logic gate is a fixed rule turning 1/0 inputs into a 1/0 output. AND needs everyone to agree "yes." OR needs just one "yes." NOT flips whatever it's given. NAND and NOR are AND/OR with the answer flipped, and remarkably, either one alone can build every other gate — making them "universal." XOR detects disagreement between inputs; XNOR detects agreement. Boolean algebra is the paper-and-pencil rulebook that lets us simplify long logic expressions into the smallest possible gate count before we ever build anything.

Key Points

  • AND = all must be 1. OR = at least one must be 1. NOT = flip it.
  • A bubble on a gate symbol always means "invert the output."
  • NAND and NOR are each individually "universal" — every other gate can be built from just one of them.
  • XOR = disagreement detector. XNOR = agreement detector.
  • Boolean algebra laws let you shrink expressions to save real gates on a real chip.
Memory Trick: "AND is strict, OR is easy, NOT is a rebel, and a bubble always means 'flip it.'" For XOR/XNOR: "X-OR eXcludes agreement, X-NOR is the opposite."

Interview Questions

  • Why are NAND and NOR called "universal gates"?
    Because any Boolean function — and therefore any other gate — can be constructed using only NAND gates, or, separately, using only NOR gates. This simplifies chip manufacturing to a single repeated cell.
  • How do you build a NOT gate from a NAND gate?
    Tie both inputs of the NAND gate to the same input signal. Since (A·A)' = A', the NAND behaves exactly like an inverter.
  • What's the practical use of an XOR gate?
    It's the core building block of binary adders (it computes the sum bit ignoring carry) and is used in parity checkers and simple encryption/comparison circuits.

Viva Questions

  • State the Boolean expression for NOR.
    Y = (A + B)'
  • What is the output of an XNOR gate when both inputs are 0?
    1 — XNOR is true whenever inputs agree, and 0=0 counts as agreement.
  • Simplify A·B + A·B' live on the board.
    A·(B+B') = A·1 = A.
