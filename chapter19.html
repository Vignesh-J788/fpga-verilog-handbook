Comparator & Seven-Segment Decoder

Two genuinely useful, very "real" circuits: a comparator (does Verilog even need gate-level logic for this?) and a seven-segment decoder — the circuit behind every digital clock and calculator display you've ever seen.

📖 Beginner Level🕐 —🧩 6 sections

1-Bit Comparator

A comparator answers one of three questions about two numbers: is A greater than B, less than B, or equal to B? At the 1-bit level, built from gates you already know:

comparator_1bit.v
module comparator_1bit (
    input  wire a, b,
    output wire gt, lt, eq
);
    assign gt = a & ~b;    // a=1, b=0 -> a is greater
    assign lt = ~a & b;    // a=0, b=1 -> a is less
    assign eq = a ~^ b;    // XNOR -> equal when both bits match
endmodule

4-Bit Comparator — Where Verilog Spoils You

Scaling a gate-built comparator to 4 bits normally requires cascading logic — comparing MSBs first, then breaking ties with the next bit down, and so on. Verilog's built-in relational operators (Chapter 10) do all of that cascading for you automatically:

comparator_4bit.v
module comparator_4bit (
    input  wire [3:0] a, b,
    output wire gt, lt, eq
);
    assign gt = (a > b);
    assign lt = (a < b);
    assign eq = (a == b);
endmodule
Important lesson: knowing the theory still matters
Writing a > b feels almost too easy — but understanding the cascaded gate-level logic hiding underneath it (which Chapter 4 introduced conceptually) is exactly what lets you reason about why a wide comparator has a longer critical path (Chapter 13) than a narrow one, and why the synthesis tool needs real silicon area to build it. Never let a convenient operator hide the real hardware cost from your thinking.
comparator_4bit_tb.v
module comparator_4bit_tb;
    reg [3:0] a, b;
    wire      gt, lt, eq;

    comparator_4bit uut (.a(a), .b(b), .gt(gt), .lt(lt), .eq(eq));

    initial begin
        a=4'd5; b=4'd9; #10;   // expect lt=1
        a=4'd9; b=4'd5; #10;   // expect gt=1
        a=4'd7; b=4'd7; #10;   // expect eq=1
        $finish;
    end

    initial $monitor("t=%0t a=%0d b=%0d -> gt=%b lt=%b eq=%b", $time, a, b, gt, lt, eq);
endmodule

How a Seven-Segment Display Actually Works

A seven-segment display is simply 7 individual LED bars (labeled a through g by long-standing convention), arranged to form a figure-8, plus sometimes an 8th "dot" segment. Lighting up the correct combination of segments draws any digit 0–9.

Turning a BCD (Binary-Coded Decimal — a 4-bit number representing digits 0–9, Chapter 1) value into the right 7-segment pattern is exactly a decoder (Chapter 18): 4 inputs in, 7 outputs, with a fixed, memorized mapping table.

The Seven-Segment Decoder

seven_seg_decoder.v — seg = {a,b,c,d,e,f,g}, active-HIGH (1 = segment lit)
module seven_seg_decoder (
    input  wire [3:0] bcd,
    output reg  [6:0] seg
);
    always @(*) begin
        case (bcd)
            4'd0: seg = 7'b1111110;
            4'd1: seg = 7'b0110000;
            4'd2: seg = 7'b1101101;
            4'd3: seg = 7'b1111001;
            4'd4: seg = 7'b0110011;
            4'd5: seg = 7'b1011011;
            4'd6: seg = 7'b1011111;
            4'd7: seg = 7'b1110000;
            4'd8: seg = 7'b1111111;
            4'd9: seg = 7'b1111011;
            default: seg = 7'b0000000;  // 10-15 are invalid BCD -> blank display
        endcase
    end
endmodule
Active-HIGH vs Active-LOW displays
This code assumes a common-cathode display, where writing a 1 lights a segment. Many real boards instead use a common-anode display, where a segment lights when driven 0 — for those, simply invert the whole output: assign seg_active_low = ~seg; Always check your specific board's schematic (Chapter 26) before wiring this up for real.

Testbench — Sweeping Every BCD Digit

seven_seg_tb.v
module seven_seg_tb;
    reg [3:0] bcd;
    wire [6:0] seg;

    seven_seg_decoder uut (.bcd(bcd), .seg(seg));

    integer i;
    initial begin
        for (i = 0; i < 16; i = i + 1) begin
            bcd = i[3:0];
            #10;
            $display("bcd=%0d -> seg=%b", bcd, seg);
        end
        $finish;
    end
endmodule

Sweeping all 16 possible 4-bit values (not just 0–9) is deliberate — it confirms the default branch correctly blanks the display for the 6 impossible BCD codes (10–15), rather than showing garbage.

Common Mistakes

  • Forgetting to check active-HIGH vs active-LOW for your specific display hardware — an inverted display shows the complement of every digit, looking like nonsense.
  • Mixing up segment bit order (some datasheets order segments differently than {a,b,c,d,e,f,g}) — always check your board's actual pin mapping.
  • Using >/< on signed vs unsigned values without realizing Verilog's default interpretation, causing unexpected comparison results for negative numbers.
  • Not testing the "invalid input" range (10-15 for BCD) — exactly the kind of edge case a thorough testbench (sweeping the entire input space) catches automatically.

Summary

A comparator can be built explicitly from gates for 1 bit, but Verilog's relational operators (>, <, ==) handle the cascading logic automatically for wider comparisons — understanding the underlying gate cost still matters for reasoning about timing (Chapter 13). A seven-segment decoder is a decoder (Chapter 18) mapping BCD digits to a fixed 7-bit lit-segment pattern, and must account for active-HIGH vs active-LOW display hardware, with invalid BCD codes explicitly blanked.

Interview Questions

  • Why might you still study gate-level comparator design when Verilog's `>` operator does it automatically?
    Understanding the underlying cascaded gate structure explains why wider comparators have longer critical paths and higher hardware cost (Chapter 13), which matters when reasoning about timing and area even though the operator itself hides that complexity.
  • What's the difference between common-anode and common-cathode seven-segment displays?
    On a common-cathode display, driving a segment HIGH lights it; on a common-anode display, driving a segment LOW lights it — the decoder's output must be inverted (or not) depending on which hardware type is used.

Viva Questions

  • How many segments does a standard seven-segment display have (excluding the decimal point)?
    7, labeled a through g.
  • What should a seven-segment decoder output for an invalid BCD input like 4'b1100 (12)?
    A blank display (all segments off), handled via the default case.
