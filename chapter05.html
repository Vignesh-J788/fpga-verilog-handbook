Sequential Circuits

Every circuit so far has had the memory span of a goldfish — no history, just instant input-to-output. This chapter introduces circuits that remember, which is what makes counters, registers, and every computer's memory possible.

📖 Beginner Level🕐 —🧩 9 sections

Why We Need Circuits That Remember

Think about a digital clock on a wall. Right now it shows some time. A second from now, it needs to show one second later — but to know what "one second later" even means, it has to remember what it was showing a moment ago. A purely combinational circuit (Chapter 4) is physically incapable of this — its output only ever depends on its current inputs, with zero memory of anything.

Analogy · A Person With No Short-Term Memory

Imagine someone who instantly forgets everything the moment it happens — every question you ask them, they answer purely based on what you're saying right now, with zero memory of the conversation so far. They could never count "1, 2, 3, 4..." because counting requires remembering what number came before. A sequential circuit is what gives a digital system that missing short-term memory.

Formally: a sequential circuit's output depends on both its current inputs and its current stored state (what it remembers from before). That stored state is called, unsurprisingly, the state of the circuit.

The Clock — A Circuit's Heartbeat

If a circuit is going to change its stored memory, something has to decide exactly when it's allowed to change — otherwise every tiny bit of electrical noise could accidentally corrupt the memory at random moments. That "permission signal" is called the clock: a signal that continuously switches between LOW and HIGH at a perfectly steady, repeating rate.

The speed of this back-and-forth is the clock frequency, measured in Hertz (Hz) — a 100 MHz clock ticks 100 million times every second. Every synchronous digital system — your phone's processor, an FPGA, anything with a "GHz" number in its spec sheet — is built around a clock exactly like this one.

The SR Latch — The Simplest Memory Cell

The most basic memory element of all is the SR Latch (Set-Reset Latch), and remarkably, it's built from just two NOR gates, each one feeding its output back into the other's input — a "cross-coupled" pair.

101Set
11ForbiddenBoth outputs try to go LOW — invalid, avoid this input
The "Hold" row is the entire point
Notice the S=0, R=0 row: the output simply stays whatever it already was. That's memory, right there, in its rawest form — the circuit is doing nothing to its inputs, yet still "remembering" its last state because of that feedback loop. Every other memory element in digital electronics — flip-flops, registers, RAM — is fundamentally a more disciplined, clock-controlled descendant of this simple idea.

Latch vs Flip-Flop — Level-Triggered vs Edge-Triggered

A plain latch (like the SR latch above) is level-triggered — it stays "open" and keeps copying its input to its output for as long as an enable signal is HIGH, and only "freezes" its memory when that enable goes LOW. A flip-flop is edge-triggered — it only ever looks at its input for one single infinitesimal instant: the exact moment the clock ticks (usually the rising edge), and ignores its input completely at all other times.

This difference matters enormously in real digital design. Edge-triggered flip-flops are what almost all real FPGA and processor designs are built from, because they give a single, predictable, unambiguous moment where data moves — which makes timing analysis (making sure everything settles before the next clock tick) vastly more manageable.

The Flip-Flop Family — A Quick Preview

There are four classic flip-flop types. We'll build each one fully in Verilog with testbenches and waveforms in Chapter 20 — for now, just get familiar with what each one does:

TypeBehavior
SR Flip-FlopClocked version of the SR latch — Set, Reset, Hold, with the same forbidden S=R=1 case.
D Flip-FlopThe simplest and most-used: output Q simply copies input D, but only at the clock edge. Perfect for registers.
JK Flip-FlopFixes SR's forbidden case — when J=K=1, instead of being invalid, it toggles (flips its output).
T Flip-Flop"Toggle" flip-flop — a single input T; when T=1 the output flips every clock edge, when T=0 it holds. The natural building block for counters.

Synchronous vs Asynchronous Circuits

A synchronous circuit changes its stored state only in step with a shared clock signal — every flip-flop in the system updates together, on the same clock edges, like an orchestra following one conductor. An asynchronous circuit has parts that can change state on their own, independent of any shared clock — like musicians each playing at their own pace with no conductor at all.

Almost every practical FPGA design you'll build in this handbook is synchronous, because synchronous designs are dramatically easier to analyze, debug, and guarantee correct — Vivado's timing analysis tools (Chapter 24) are built entirely around this assumption.

A Sneak Peek: Finite State Machines (FSMs)

Once you have memory (state) and a clock, you can build a Finite State Machine — a system that is always sitting in exactly one "state" out of a fixed, known set of possible states, and moves to a different state based on its current state plus its current inputs. A traffic light is a perfect real-world FSM: it's always in exactly one state (Red, Yellow, or Green), and a timer input moves it to the next state in a fixed sequence.

Where you'll actually build one
We'll design a complete traffic-light controller as a real FSM, in real Verilog, in Chapter 22. For now, just take away the core idea: state + clock + rules for what happens next = a Finite State Machine — one of the single most useful patterns in all of digital design.

Summary

Sequential circuits add memory to digital logic — their output depends on both current inputs and a remembered state. A clock provides the steady heartbeat that controls exactly when that memory is allowed to update. The SR latch (two cross-coupled NOR gates) is the simplest possible memory cell, with Set/Reset/Hold behavior and one forbidden input combination. Latches are level-triggered (open the whole time enable is HIGH); flip-flops are edge-triggered (react only at one clock instant), which is why almost all real FPGA designs use flip-flops. The flip-flop family (SR, D, JK, T) each behave slightly differently, and chaining state + clock + transition rules together gives you a Finite State Machine — the pattern behind counters, controllers, and traffic lights alike.

Key Points

  • Sequential circuit = f(current inputs, current stored state) — combinational circuits have no state at all.
  • Clock = steady repeating signal that times when memory updates happen.
  • SR Latch: S=1,R=0 → Set. S=0,R=1 → Reset. S=R=0 → Hold. S=R=1 → Forbidden.
  • Latch = level-triggered. Flip-flop = edge-triggered. FPGA designs almost always use flip-flops.
  • D flip-flop is the workhorse of registers; T flip-flop is the workhorse of counters.
  • FSM = state + clock + transition rules.
Memory Trick: "A LATCH is like an open door — anything can walk through while it's open. A FLIP-FLOP is a door that only opens for one split second, at the clock tick, then slams shut."

Interview Questions

  • What is the fundamental difference between combinational and sequential circuits?
    Combinational circuit outputs depend only on current inputs with no memory. Sequential circuit outputs depend on current inputs plus a remembered internal state, updated in step with a clock.
  • Why is the JK flip-flop considered an improvement over the SR flip-flop?
    It removes the forbidden input case — when J=K=1, instead of being invalid/undefined like SR's S=R=1, the JK flip-flop simply toggles its output, giving it a defined behavior for every input combination.
  • Why do FPGA designs favor synchronous design over asynchronous?
    Synchronous designs update all state elements together on a shared clock, making timing behavior predictable and analyzable with standard tools; asynchronous designs are far harder to verify and are prone to race conditions.

Viva Questions

  • How many NOR gates make up a basic SR latch?
    Two, cross-coupled so each gate's output feeds into the other gate's input.
  • What does a T flip-flop do when T=1 on every clock edge?
    It toggles — flips its output state — on every active clock edge, making it ideal for building counters.
  • Is a flip-flop level-triggered or edge-triggered?
    Edge-triggered — it only samples its input at the instant of a clock edge (commonly the rising edge).
